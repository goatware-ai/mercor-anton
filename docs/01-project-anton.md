# 👋 Project Anton

> **Project Anton | SWE Trajectory QC Annotation** — This initiative creates and evaluates rigorous software-engineering tasks and the agent trajectories that attempt them. A task creator authors one complex task in Harbor format and generates at least two controlled agent rollouts. Two eligible rollouts are selected as Trajectory A and Trajectory B. Both selected trajectories must be rated `PASS` or `PARTIAL`, and at least one must be generated by a Gemini-powered SWE agent. An annotator scores both trajectories, answers 5–10 task-specific binary rubrics, and submits one pairwise preference. A reviewer evaluates each annotation for correctness.
